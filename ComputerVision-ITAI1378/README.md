# Computer Vision (ITAI 1378)

This folder contains my work from the Computer Vision course at
Houston Community College.

## Projects
- [Crib Sentry](Crib-Sentry): finds the child, the crib, and hazards in a photo and gives one of four results: left the crib, hazard present, not visible, or all clear
- [Chihuahua or Muffin CNN](Chihuahua-Muffin-CNN): trains a CNN to tell Chihuahuas from muffins and tests how the learning rate changes the validation accuracy
