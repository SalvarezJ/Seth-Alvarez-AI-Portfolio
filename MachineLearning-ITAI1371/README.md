# Machine Learning (ITAI 1371)

This folder contains my work from the Intro to Machine Learning course at
Houston Community College.

## Projects
- [Telco Churn EDA](Telco-Churn-EDA): looks at the data of 7,043 telecom customers
  to find what goes with churn and to plan how to prepare the data for a model
- [Wine Classification](Wine-Classification): trains Logistic Regression and a Decision Tree on the Wine dataset
  and tests how the choice of features changes the accuracy
